# Job Market & Skill Demand Dashboard

## Project Overview
This project analyzes job market trends and skill demand across different roles and locations.  
Using *Python (Pandas, Seaborn, Matplotlib)* for data preprocessing and visualization, and *Power BI* for dashboard creation, it provides insights into salary distribution, hiring trends, and skill demand.

## Key Insights
- *Top Roles:* Junior Data Analyst and Data Engineer have the highest average salaries.
- *Experience Impact:* Senior-level roles earn the highest salaries, followed by mid-level positions.
- *Top Hiring Locations:* Mumbai and Hyderabad lead in hiring.
- *KPIs:*
  - Average Salary: *10.75 (normalized value)*
  - Total Companies Hiring: *10*
  - Total Jobs: *10*

## Tools & Technologies
- *Python Libraries:* Pandas, Seaborn, Matplotlib  
- *Data Visualization:* Power BI  
- *Data Source:* Job listings dataset (cleaned using Python)

## Dashboard Highlights
- Interactive slicers for *Job Title, **Experience Level, and **Location*
- Salary comparison by *role* and *experience*
- Percentage of jobs by *location*
